# V21：中美双市场策略驾驶舱与前瞻治理

**研究数据截点：2026-11-20收盘。版本日期：2026-11-21。**

## 结论

这一轮不再针对已知的2026年市场继续优化止损阈值，而是把V18冻结基准、V20公开双动量否决实验、实际模拟持仓和可交易时点放进一套完整的、**无需联网即可打开的交互式网页**。V21增加了数据一致性检查、策略晋级准则、固定哈希的前瞻信号存档和对照分析。**V21没有把未经样本外验证的新模型设成默认买卖策略。**

## 3. V21真正新增的四个工程化改进

**（1）独立网页仪表盘。** 单一HTML离线文件，包含完整本地样式与交互脚本，无CDN：总览、A股、美股、中美联动、稳健性审计、交易与记录六个页面；可切换回测策略、年份区间；可查看归一化净值曲线及悬浮信息、目标/实持差异、年度收益、市场成交额、严峻风险信号和研究成本。可筛选并下载逐周模拟交易CSV、完整研究JSON与冻结信号记录JSON。桌面及手机浏览器均经过渲染检查。

**（2）模型晋级纪律。** 默认只有满足“历史回撤改善超过2个百分点、区块Bootstrap区间不包含零、成本及另一个成交时点表现不崩溃”才允许将候选标记为*历史检查通过*；仍必须另外进行未来行情验证，不能自动买卖。美股V20过滤器虽然回撤改善2.834个百分点，但区块重抽样90%区间是[-0.778,+1.664]个百分点，包含零，因此 **V21默认不晋级**；A股过滤器也未晋级。

**（3）数据与日期完整性。** 检查每个市场的实际周起始日、日期唯一性、正价格、缺失值与仓位守恒。A股与美股历史时间不能按313条记录的位置配对。网页标识价格数据时间、成交时点与模型来源。若行情不完整则拒绝静默生成新的可信信号。

**（4）前瞻锁定信号。** `research_outputs/V21_frozen_signals.json` 保存CN和US的当前模型目标、日期截点、底层数据文件SHA256、记录SHA256。它不是实盘委托记录，也不能事后将新的行情回写到此前的信号。后续新周数据可另行登记，再比较模型预测与模拟成交。

## 4. 重点压力条件

- A股V18：原手续费模型的累计收益+85.24%，2倍费用+74.28%，3倍费用+63.96%；说明交易成本较高，是工程化首要风险。
- 美股V20外部否决：原成本、次周开盘累计+98.50%、最大回撤-19.58%；手续费2倍+95.07%，改为次周收盘累计+84.40%，2026年收益由+9.64%降到+1.76%。**成交时点显著改变结果。**
- 两套模型的2013/2020—2026长期复权回测不能解释未来收益；多次参数搜索会夸大表面稳健性。
- 中金/趋势动物/Faber/Antonacci等公开方法只借鉴信号逻辑，未对任何私人基金、投顾或博主真实操作形成复现。

## 5. 如何使用网页

- **最快**：直接双击 `web/index.html` 或下载独立 `V21_中美量化策略可视化看板.html`；网页为离线研究快照，打开不需要联网或Python。
- **本地策略开发**：项目根目录运行 `python scripts/build_v21_dashboard.py` 重新用本地审核数据生成HTML及信号存档。
- **既有Streamlit工具**：运行 `python -m pip install -r requirements.txt`、`python -m streamlit run app.py`，在左侧选择“V21完整策略驾驶舱”，嵌入展示新版网页。
- **复核代码**：运行 `python -m pytest -q tests/test_v21.py` 和 `python -m pytest -q`。
- **部署静态站**：将 `web/index.html` 上传到任意静态网站托管服务作为主页（例如GitHub Pages或Cloudflare Pages）。这不包含自动获取行情、登录或自动下单；目前也未部署成公网URL。
