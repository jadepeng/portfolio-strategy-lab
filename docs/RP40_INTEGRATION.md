# rp40 接入实盘决策链路：变更说明

## 设计
- **在目标权重这一层混合，不拆两个资金账户。** `rp40 = 60% × V18 目标 + 40% × 风险平价目标`。混合后的目标照常走 `simulate_multi_asset` 和实盘票据链路，所以换手死区、风控优先减仓、盘中止损的冷静期截断（`clip_weekly_risk_additions`）、T+1 和整手约束都**原样生效**，不需要另外记账。
- 风险平价那 40% 不持有货币 ETF。100% 资金都会配到四类风险资产里（单一资产上限 60%）。
- **只适用于 A 股。** 美股账户选 rp40 会被拒绝。
- **不回退到 V18。** rp40 没有离线研究快照，如果在线重算失败，返回空模型，执行门控会直接**阻断计划**，不会悄悄改按 V18 下单。

## 文件
| 文件 | 改动 |
|---|---|
| `strategy_core/risk_parity_sleeve.py` | 新增 `blend_targets`、`RP40_SHARE=0.40` |
| `strategy_core/api.py` | 对外导出 `blend_targets`、`RiskParityConfig`、`RP40_SHARE` |
| `live/engine.py` | `recompute` 生成 `models.CN.rp40`（标签「V18 + 40%风险平价底仓 · 在线重算」） |
| `live/store.py` | 版本列表加入 `rp40`；新增 `MARKET_ONLY_VERSIONS`，限制 rp40 只用于 A 股 |
| `live/service.py` | 新增 `NO_FALLBACK_VERSIONS`，rp40 缺模型时不回退 |
| `web/ptms.js`、`web/template.html` | 账户设置下拉框和研究看板加入 rp40 |
| `tests/test_rp40_integration.py` | 测试资金守恒、因果性、share=0 时与 V18 逐周一致、回撤和费用改善、版本注册 |

数据库无需迁移：`strategy_version` 是 TEXT 字段。

## 上线建议
1. 运行 `pytest tests/`。
2. 先建一个**示例账户**，选 rp40，在纸面上跟踪 4–8 周。
3. 每周对照 `frozen_signals` 记录和真实成交，确认没有问题后再切到真实账户。
