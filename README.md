# 中美股市风险策略实验室 V1

一个可本地运行的 Streamlit 风控与历史回测工具。支持纳斯达克100、创业板；比较买入持有、30周均线和三级风控；可调仓位阈值、美债指标、交易成本，并生成调仓日志。

## Windows 运行

1. 安装 Python 3.10+。
2. 解压本项目，双击 `run_windows.bat`，等待浏览器打开 `http://localhost:8501`。
3. 或命令行：`python -m pip install -r requirements.txt`，`python -m streamlit run app.py`。

## WSL/Linux 运行

在独立虚拟环境中运行（避免 Ubuntu 的 externally-managed-environment）：

```bash
cd risk_strategy_lab
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py --server.address 0.0.0.0
```

之后可以在 Windows 浏览器打开 `http://localhost:8501`。

## 数据来源

- 优先使用 Yahoo Finance 下载每日收盘数据后重采样到周五，指数 `^NDX`、`399006.SZ`，以及TLT。用户的网络必须可以访问 Yahoo Finance。
- 下载成功后在 `market_data/` 缓存 CSV，下一次断网可使用旧缓存。也可在侧边栏上传 `Date,Close` CSV（每日或周度均可）。
- 真实美债收益率模式支持从 [FRED DGS10](https://fred.stlouisfed.org/series/DGS10) 下载 `DATE,DGS10` CSV（单位百分比点，如 4.92）。若没有文件，程序不会以TLT冒充国债收益率。
- 随附 `verified_results.json` 是2026-11-21基于Longbridge历史周K、同一规则计算的静态快照。实时重新下载后可能因数据供应商、周线时区和调整方式产生细微差异。

## V1策略与测算口径

- 周线信号，下一周生效；没有未来函数。
- 一级预警：回撤8%或跌破10周均线，仓位75%。
- 二级防御：回撤12%或跌破30周均线，仓位50%。
- 三级极端：回撤20%或跌破30周均线且回撤16%以上，仓位25%。
- 回补：重新站上10周均线+四周收益正+回撤小于16% → 50%；站回10和30周均线且四周收益正、回撤小于10% → 100%。
- 美国美债代理（可选）：TLT八周跌4.5%以上、纳指距26周高点不到6%且近八周相对平稳 → 最多75%。真实10年国债收益率（可选）为八周上行35bp触发。
- 交易成本15bp/单程调仓名义金额；默认现金零收益。均为指数**价格**模拟，而非真实产品净值。不含股息、汇兑、税费、交易所实际滑点、基金折溢价。不可直接用模型仓位等比例推到全部家庭资产。
- 不是数据挖掘后选出的最优参数。需做滚动样本外验证、参数敏感性、组合资产穿透、极端流动性压力测试。

## 数据校验

使用 `python -m pytest tests` 运行基础单元测试（需先安装 `pytest`）。验证信号的下一周执行、恒定价格时不虚构收益、基准策略不调仓。

**风险提示**：本项目用于研究与复盘，不自动下单，也不是收益保证。

## V2：红利 × 科技动量轮动（新增）

左侧页面导航选择 **“红利科技动量轮动”**。这一页和V1风险择时共用一个本地应用，支持修改周期、切换缓冲和风险阈值，以及上传两份数据、比较收益回撤、下载每周配置记录。

- **绝对趋势：** 指数站上30周均线、动量为正才允许配置。常规每4周重新评估；科技仓位每周响应破位/回撤，紧急降低持仓上限。
- **比值：** 创业板/中证红利原始指数比值0.4和0.6仅作为可选的偏好倾斜，默认关闭。原始指数刻度与ETF价格、复权价格不能混用。这个功能不是旧V2-B规则的逐字复现，而是可单独检验的实验。
- **基准：** 科技单持、红利单持、50/50定期再平衡、纯动量、动量加风险、动量加比值倾斜及当前参数方案。注意各基准均为价格指数比较。
- **自查：** `python -m pytest tests -q`，12项测试包含不偷看未来、不加杠杆、准确按上期目标持仓计算周收益、调仓成本降低收益。

**已核验快照**：`verified_rotation_results.json` 保存2026年11月21日使用Longbridge历史周收盘价对比的结果，可用于离线查看结论；不是逐周原始行情，也不能用来重新调参。实际动态计算仍需联网下载或上传CSV。

**关键信号：** 2026年11月20日收盘后，在这个严格的战术轮动模型中，科技与红利均未满足绝对动量要求，下周目标为0%科技、0%红利、100%现金。**这绝不等于建议清仓所有长期核心资产，也不应补做错过的全部历史卖出交易。**

### 运行限制

指数价格并不等于完整的投资收益，尤其是中证红利价格指数不含再投资股息。要严谨比较不同资产的长期收益，应改用中证红利全收益H00922、科技全收益或真实ETF复权净值，并在独立时期验证参数稳定性。美元纳指与人民币A股仍应分开计算汇率及总组合风险。

数据文件示例仅展示 `Date,Close` 格式，不是真实行情，且不足60周，不能直接用于回测。动态回测时两个指数至少需要60个共同的完整交易周。

## V7｜红利权益主体 + 511880货币ETF作为战术现金（2026-11-21）

新增：`fusion_v7.py`、`pages/6_V7红利与货币ETF现金增强.py`、`scripts/reproduce_v7.py`、`market_data/longbridge_etf_fwd_2020_2026_v7_money.csv` 和 `verified_fusion_v7_results.json`。

V7不是重新调整趋势动物的私有温度算法。它沿用 V6/V5 已编码的趋势代理规则，在资产配置层对比常驻红利20%/30%/40%/50%，新增作为**可交易资产**的场内货币ETF代理（银华日利511880前复权周线），并且将交易手续费拆分成权益ETF每侧15bp、货币ETF每侧1bp（均可调）。未投资现金不再被错误地收取交易费。信号周末收盘生成，使用**下一周收盘价格**模拟成交；不使用未来价格。

最新验证区间为 2020-10-12 至 2026-11-20（周一标记的313根周线），其真实区间终点的CSV记录日期为`2026-11-16`，对应当周周五`2026-11-20`收盘；切勿把日期误认为周一时已知收盘。

**标准比较**（2020—2026，累计收益/最大回撤）：

- V6原配置红利核心20%，闲置现金不计息，统一新费用：**+30.89% / -10.63%**。
- V6红利核心20%，使用511880历史前复权价代理，统一新费用：**+36.88% / -9.14%**。
- 红利核心30%加货币ETF：**+42.02% / -9.60%**。
- 红利核心40%加货币ETF：**+47.01% / -10.25%**。
- 红利核心50%加货币ETF：**+52.39% / -10.89%**。
- 单纯一直持有515180 ETF：**+78.82% / -16.97%**，提醒高现金策略有机会成本。

重要：这是**2026年下跌事先已知的回顾性优化**，红利底仓加大带来的历史收益不等于选股/择时alpha，也不保证未来稳定盈利。原V6（旧费用算法）+25.73% / -12.48%**不能**直接用于与V7结果作因子优劣比较，因为此前对现金的虚拟换手也扣了15bp成本；V7所有方案均按同一合理的分品种费用口径重算。

按2026-11-20可交易ETF复权行情：红利(515180)近6周-1.0%，近26周+2.9%，在30周均线上方约+1.5%；创业板(159915)近26周-43.5%。红利适合优先研究但短期涨势不是单向。对策略子账户建议用20%红利常驻作为防守下限，30%—40%作为待审慎试行的中性范围，其余保持科技趋势机动与场内货币ETF可用资金。**V7用ETF代理回测下，红利核心30%的当前模型目标是科技0%、红利44%、货币ETF56%；红利核心40%时为科技0%、红利52%、货币ETF48%。** 这不是全部家庭资产的调仓目标，也不适用于直接一次性满仓切换，真实当前持仓仍需由账户核实。

**现金收益假设**：511880历史前复权价格从91.272到100.991，等效年化增长约1.70%，但没有把基金分红逐笔与官方NAV勾稽，**不能称作已核对的基金总收益**。2026-11-19公开七日年化收益率约1.085%，511990在2026-11-20约1.003%。对未来建议使用0.5%—1.5%年化敏感性，不要外推历史1.7%；现金替代的成本和收益还受持有天数、佣金优惠、价差及折溢价影响。

511990通常在100元面值附近交易，收益主要来自收益分配/账户权益而非二级市场报价涨幅，**绝不直接用511990的收盘价涨跌回测货币基金总收益**。511880模式主要在全价净值累积及年度分红表现，仍需核查调整行情在分红前后的精确表现。货币ETF不保本，存在流动性、底层资产、交易折溢价、收益率变化等风险。交易/T+0、到账与资金可用时间以券商规则为准。实际银行账户应急款不在场内货币ETF模型中。

研究发现：给红利增加“短期相对动量转强额外买20%”在当前样本中**降低**了累计收益、**扩大**了回撤，故V7仍默认不启用额外红利追涨规则。下一步应冻结参数，开展未来实时信号记录及独立的其他年份/标的验证。
