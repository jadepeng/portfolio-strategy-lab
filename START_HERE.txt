V22 中美双市场量化策略驾驶舱（历史研究与盘中风控模拟）
1. 解压项目 ZIP 至本地普通文件夹
2. Windows 双击 run_dashboard_windows.bat；或浏览器打开 web/index.html
3. 点击左侧“盘中减仓线”第七页，查看研究性候选线和真实30分钟事件样本
4. 页面是截至2026-11-20的离线快照，不是实时行情、交易提醒或自动下单软件
5. 如需重算：安装 requirements.txt，依次运行 scripts/reproduce_v22.py、scripts/sensitivity_v22.py、scripts/build_v22_dashboard.py
6. 如需编辑周频策略，请执行 python -m streamlit run app.py（Streamlit浏览器渲染尚未在本环境验收）
7. 中美两策略账户独立。当前QQQ长期核心30%不会被V22减仓；红利候选止损线过近，请勿直接用于自动实盘
8. 参见 V22_中美双市场盘中有效跌破减仓线研究报告.md
