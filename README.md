# ETF量化决策系统 (ETF Quantitative Decision System)

> **面向严肃投资者的中美双市场「每周可用」个人量化策略平台与交易控制台。**  
> 统一行情跟踪、策略仲裁、盘中防守、真实账本与复盘审计，做到「打开知买卖、执行对得上、周末明偏差」。

---

## 🎯 核心定位

很多量化项目死在回测与实盘交接的灰色地带：回测曲线光鲜亮丽，但打开软件不知道今天该不该点、部分成交了待办单直接消失、实盘建账默认塞进 10 万虚假本金、行情断了还在出虚假调仓建议。

**ETF量化决策系统** 专为解决交易全链路的真实痛点而设计：
1. **周频稳健配置 + 盘中非对称风控**：A 股五资产宏观轮动与美股多周期趋势稳固基本盘，日内 30 分钟 K 线有效跌破仅负责分档减仓避险并执行冷静期。
2. **分市场独立执行门控 (Data Gate)**：根据数据鲜度、日历核验与开盘时区（次交易日 09:30）严格校验执行窗口；数据异常自动阻断计划单生成，绝不给出误导性建议；中美市场互不干扰。
3. **真实账本与严格交易纪律**：支持真实/示例账户、部分成交追踪与余量接续、流水幂等防重与不可变冲正、券商对账单 (CSV) 导入、T+1 制度与整数手约束。
4. **全透明时间加权复盘 (TWR)**：真实收益率彻底剥离出入金干扰，严格拆分「计划完成率」与「纪律遵守率」，提供审计级 Markdown 报告导出与带校验和的数据库全量备份恢复。

## ⚡ 快速开始

### 1. 环境准备
推荐使用 Python 3.10+ 环境：
```bash
# 克隆仓库
git clone https://github.com/jadepeng/portfolio-strategy-lab.git
cd portfolio-strategy-lab

# 安装开源依赖（行情、计算与轻量回测）
python -m pip install -r requirements-open-source.txt
```

### 2. 启动控制台
- **Windows 用户**：直接双击根目录下的 `run_dashboard_windows.bat`。
- **命令行方式**：
  ```bash
  python scripts/serve_dashboard.py
  ```
启动后在浏览器打开：**http://127.0.0.1:8765**。服务默认仅绑定本机回环地址，无需配置数据库或外网服务。

## 🛡️ 交易与风控纪律

1. **执行时间窗口严格隔离**：
   - A 股周频信号于周五收盘后形成，最早可执行窗口为**下周一 09:30 开盘后**。
   - 美股周频信号于美东周五收盘后形成，执行窗口为**下周一美东 09:30 开盘后**。
   - 美股收盘晚于 A 股，A 股计算跨市场风险时仅使用上一完整交易周的美股数据，严禁前视泄漏。
2. **盘中跌破与冷静期机制**：
   - 每日开盘前冻结 20 日趋势线与 3% 冲击防守线。
   - 盘中必须连续两根已完结的 30 分钟 K 线有效收于防线下方，才触发战术仓分档减仓。
   - 减仓后进入 **3 个交易日冷静期**：冷静期内严禁周频模型加仓，违规资金全部强制转入货币工具。
3. **真实账本完整性**：
   - 每次买卖记录支持部分成交确认，未达成部分继续在待办列表中等待，直至余量取消或补足。
   - 任何失误操作严禁物理篡改数据库，必须通过 `reverse_event` 发起审计冲正，保留完整履历。

## 📚 现行策略与历史策略的边界

- **现行研发入口：** [`strategy_core/api.py`](strategy_core/api.py)（[接口契约](docs/STRATEGY_API.md)）。它持有独立的 A 股 / 美股策略、市场状态、盘中减仓、风控、行情分析及必要的基础模型副本；所有现行函数、配置类、模块和信号列均采用业务语义命名，不再携带 V17/V18/V20 等研发版本号。`live/` 和当前研究看板统一导入稳定入口 `strategy_core.api`，今后优化只修改现行实现，不改变 `history/` 冻结版本。
- **历史归档：** [`history/`](history/README.md) 保存 V1—V22 的研究源码（含 `history/v13/` 到 `history/v22/`）、研究报告、旧版应用及验证结果。历史回测脚本和历史研究页面继续依赖归档版本，避免被现行策略迭代改变结论。
- **旧版 Streamlit：** `run_linux.sh` / `run_windows.bat` 仍可启动 `history/apps/app.py` 及其 `history/apps/pages/` 中的 18 个历史研究页面，但正式交易决策台请使用 `run_dashboard_linux.sh` / `run_dashboard_windows.bat`。
- **验证数据：** 根目录原 `verified_*.json` 迁至 `history/verification/`，`market_data/` 与 `research_outputs/` 维持原路径。

```bash
python -m pytest tests -q
```
