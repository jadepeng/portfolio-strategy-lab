# V22 中美双市场盘中有效跌破减仓线：研究报告

**研究截止：2026-11-20（各市场当地收盘）｜性质：历史行情研究与离线模拟，非自动交易系统。**

## 1. 结论

V21/V18沿用周频趋势信号，在突发的单日极端下跌中可能直到周末甚至下一周才执行减仓。V22新增独立的30分钟事件驱动执行引擎，用前一个**已经结束的交易日**计算预先承诺的减仓线，依靠已完成的30分钟K线确认跌破，再在下一根合法K线的开盘时刻按价格及交易成本模拟执行，以缩短风险响应时滞。该引擎只生成研究交易意图；目前不联网持续监控、不与券商下单、不改变V18冻结的长期基准回测。

**不可把一次极端下跌样本中的收益改善，外推为完整2026年或长期稳定的止损效果。** 真实样本中，QQQ急跌窗口减轻了亏损；红利与创业板窗口由于后续反弹和交易成本反而表现更差。

## 2. 和已有模型的关系

- **A股周频：** V18继续决定创业板159915、红利515180、国债511260、黄金518880、货币511880的风险预算与目标仓位。
- **美股周频：** V18继续决定QQQ核心与趋势仓、BIL短债现金仓；公开双动量V20仅为候选过滤器。
- **V22日内层：** 针对已有可卖风险仓（优先科技、其次红利的战术仓），提供阶段性风险减仓。触发后的资金分别进入人民币货币仓或美元短债仓，绝不跨币种合并。止损冷却期内，新的周频加仓意图须先经`clip_weekly_risk_additions`拦截。
- **默认状态：** V22为可选的**离线研究/模拟**模式；未并入V18真实周频持仓回测，也未打开自动交易。

## 3. 减仓线如何在开盘前确定

参数默认值：20个完整日收盘价观察最高值、10日收盘均线、日收益对数波动率20日样本下限0.4%、峰值减去2.5倍当日波动价格、10日均线减去1.0倍波动价格、前一日收盘急跌线3%。

设上一交易日收盘价为`C_prev`、20日最高**收盘价**为`H20`、10日均线`MA10`、对数日收益标准差`σ`（至少0.004）：

```
趋势参考线 = max(H20 - 2.5 * σ * C_prev, MA10 - 1.0 * σ * C_prev)
急跌保护线 = C_prev * 0.97
```

如果`C_prev`已经小于等于趋势参考线，表示之前的趋势位早被跌破，不能在当前开始一段历史回放时借那条旧线“事后卖在高位”。当日仅采用新的急跌保护线；否则使用`max(趋势参考线, 急跌保护线)`。实际持仓内的活跃减仓线不能在持仓延续过程中往下调低，持久化状态以防复位追认。

以上是**研究设计**，并非市场普遍最优公式；特别是红利波动率较小，导致减仓线可能非常贴近当前价格，假破位和反复交易风险较大。

## 4. 盘中“有效跌破”的判定与执行

1. 使用各交易所正规交易时段的30分钟K线（A股9:30—11:30、13:00—15:00；美国纽约9:30—16:00）。忽略单根K线的最低价刺破；当**连续两根已完成K线收盘价低于当天预定线**，生成第一档卖出意图。
2. **不得用触发K线本身的开盘价成交。** 在下一根合法30分钟K线开盘时按可观察价格模拟成交；若确认发生在A股最后一根K线，则最早到下一交易日开盘。卖出价含单边0.10%滑点、0.15%费用假设（均为研究参数）。相邻K线的收盘时刻与开盘时刻可能有相同时间标签，但先观察收盘、再模拟下一K线开盘。
3. 第一档减持`50% × (当时实际仓位 - 核心保护下限)`；连续跌破扩大至4根且已完成第一档后，第二档将剩余战术仓减至核心下限。跳空严重下跌要求第一根K线**收盘后**确认，仍不能在已知会跌时假定以当日开盘高价成交。
4. 触发后冷却3个实际交易日，禁止周频信号马上追买。解除条件是冷却结束且周频趋势重新给出合法入场信号，而不是价格稍回到线以上便立即买回。
5. A股上市ETF的卖出可用数量、申购交割、停牌、跌停及券商账户规则必须在**实际交易接入时**逐笔校验；引擎可输入`sellable_weight`阻止在不可卖时虚构成交。A股股票类ETF的交收规则应按具体ETF与市场制度核对，美股也需验证盘中流动性与交易时段。
6. 极端跳空、跌停、流动性消失时，减仓线不是保证成交价；遇到无法成交必须保留待执行或未成交的状态，并报警，而不是把指令计为已经卖出。

模型**有意设定**期初仓位：创业板35%、红利44%、QQQ100%（保留30%核心）。交易完成后只转移到现金，不假设提前知道底部并买回；A股每个交易日官方15:00收盘用于估值，但不把15:00重复的行情快照视为可交易K线。源为Longbridge前复权30分钟开/收盘价；图表、时间戳与成交意图见`research_outputs/V22_event_*`。

**重要边界：** 当前美股V18实际上只有QQQ长期核心30%，即使QQQ出现上述样本同样的价格路径，V22的30%核心保护会阻止额外卖出，因此该+1.71个百分点改善不属于当前美股目标组合的收益。

对2.5%、3%、4%急跌线、2/3根确认K线、10/30bp滑点做了36行事件压力测试：QQQ事件改善区间约+1.25到+1.97个百分点，但创业板与红利窗口依然存在负贡献。事件是**事后挑选**、时间太短，不能进行长期优越性断言。

## 7. 工程文件与复现

- `v22/intraday.py`：时间安全的30分钟信号判定、两档减仓、跳空、一致状态与成本模拟。
- `v22/allocation.py`：中美各自风险仓位转入本币货币/短债、防止周频加仓立即覆盖冷却指令。
- `scripts/reproduce_v22.py`：使用固定真实事件样本重跑触发、净值、交易日志，不能冒充全年回测。
- `scripts/sensitivity_v22.py`：参数及成本的局部敏感性对照。
- `scripts/build_v22_dashboard.py`：把冻结V21研究快照及V22事件独立打包成不依赖CDN的HTML。
- `pages/19_V22盘中减仓线与双市场风险执行.py`：可复跑的Streamlit研究页面。
- `tests/test_v22.py`：全K线确认、下一K线开盘、持仓核心保护、冷却、A股可卖库存、日历和数据隔离等测试。

```bash
python scripts/reproduce_v22.py
python scripts/sensitivity_v22.py
python scripts/build_v22_dashboard.py
python -m pytest -q tests/test_v22.py
python -m streamlit run app.py
```

离线网页：`web/V22_盘中减仓线与双市场策略驾驶舱.html` 或 `web/index.html`。下载后浏览器直接打开，网页包含原V21的六个页面及V22第七页盘中风控，但**不实时接收行情**。数据日期统一保留中美各自真实交易日期；中美账户、收益分开统计。

## 8. 下一步达到模拟盘运行级别的必要事项

当前不应直接打开自动实盘止损。还需接入可追溯的实时5分钟或1分钟行情、交易所交易时段日历、可靠的数据迟到检测、经纪商实际可卖数量和订单状态、分时段滑点模型，以及异常停牌/跌停/熔断场景的拒单与重试。至少用跨年份完整高频历史和未来连续模拟交易做校验，比较原V18与V18+V22的**真正组合层面的**回撤、交易成本、全年收益、误触发次数和时间同步准确率。
