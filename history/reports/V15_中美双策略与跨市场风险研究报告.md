# V15：A股与美股独立策略 + 美股影响A股风险闸门

研究数据截止：2026-11-20收盘；生成日期：2026-11-21。**以下均为历史模拟，不是实盘业绩或保本承诺。**

## 1. 两套账户、两个策略、一个跨市场风险接口

| 维度 | 中国A股 | 美国股市 |
|---|---|---|
| 投资对象 | 创业板159915、红利515180、10年国债511260、黄金518880、货币511880 | QQQ纳指100、BIL短期美国国债 |
| 主策略 | V14五资产趋势/成交量预警/状态机 | 简单、独立的QQQ 30周均线趋势 |
| 配置 | 自适应动态仓位 | 可选战略QQQ核心（默认30%）+ 70%趋势战术仓 |
| 市场信号 | 中证全指成分股篮子成交额代理 + 本地科技/红利走势 | QQQ趋势；SPY、SMH、RSP用于美国风险识别 |
| 跨市场影响 | 允许美股趋势和科技退潮**冻结创业板新增战术仓** | 美股本身不受A股信号影响 |
| 计价货币 | CNY | USD |
| 回测成交 | 下一完整周的周线收盘 | 下一完整周的周线**开盘**（另有收盘敏感性模式） |

这两套收益率不能直接相加；真实总资产回测须另行纳入USD/CNY汇率、换汇费用、两地节假日、税务。

## 2. 没有未来数据：周五时差是核心

周线存储标签是**该周周一**，价格代表本周最后一个交易日收盘。美国周五16:00 ET收盘时，北京已是周六凌晨（冬令时约05:00）；中国周五15:00的信号**不可能知道同一周的美股周五收盘价**。

因此 `v15/cross_market.py` 在中国第t周信号中只使用第t-1个完整美国周线的因素，向后兼容A股原来的“下一周收盘成交”口径。代码里 `us_source_week` 精确显示用于每笔中国策略信号的美国行情日期。2026-11-16的A股信号使用美国**2026-11-09周**数据，绝不使用美国11月20日收盘数据。未来如做周一开盘抢先风控，必须另建独立的美国日线/中国日线匹配和次日开盘成交回测，不能让周线模拟冒充实时隔夜执行。

## 3. 美股因素如何影响A股

`US_bear`：QQQ跌破30周均线、SPY跌破13周均线；`US_shock`：QQQ单周急跌4.5%以上，或半导体SMH近4周明显跑输QQQ、同时QQQ跌破10周均线；`US_warning`：SMH近4周明显跑输QQQ且等权重RSP近4周明显跑赢SPY。

- 正常：A股V14完全独立决策；美股不会直接触发红利或国债平仓。
- 预警：限制**新增**创业板目标至20%和上一周已准许目标中的较高值，不追高但不主动卖出原有技术仓。
- 熊市：新增科技仓上限12%；熊市叠加冲击：8%。仓位限制不会直接削减上一周已准许的科技仓位，因为趋势退出由A股本土V14负责。
- 被限制的目标科技预算转入人民币货币ETF，绝不将BIL美元收益计入A股人民币账户。
- 当美国风险消退，解除限制，由国内趋势状态机决定能否重新试仓。

这些是可关闭的风险限制，不是证明“美股一定领先A股”的预测模型。没有可验证的纳指期货、真实全市场拥挤度、日度广度数据时，不能宣称已经包含这些信号。

## 4. 可复现结果与风险

同一历史数据和成本设置下：

| 策略 | 2020-11—2026-11总收益 | 最大回撤 | 2026年至11月20日 |
|---|---:|---:|---:|
| A股原V14 | +78.46% | -9.39% | +13.26% |
| A股V15：加入美股风险闸门 | +79.42% | -9.39% | +13.25% |
| 美股QQQ 30周纯趋势 / BIL | +84.17% | -23.53% | +11.00% |
| 美股30%战略QQQ + 70%趋势 | +94.63% | -25.57% | +7.65% |
| 美股QQQ全程持有 | +110.79% | -35.06% | -0.42% |

**重要：** 美股表的样本实际起点是2020-11-23；A股表起点是2020-10-12。不能不加区别地比较两者累计收益大小，也不能认为A股的2026年约13%已经具备前瞻验证。A股联动带来的收益差小于1个百分点，2026反而略有下降，不能认为这种风险闸门已证明有效。

**成交口径敏感：** 美股独立策略若改用下周收盘才成交，2026收益会显著劣化；可在V15 UI中切换下一周开盘/收盘，直接观察差异。A股继承V14原本下一周收盘成交，不应把两种成交口径包装为完全可比的单一收益排名。ETF前复权数据经分价位压缩储存为美股美分级，分红再投资/税务具体计算仍需券商流水核实。

## 5. 2026年11月20日收盘的研究目标仓

- A股策略子账户：创业板0%，红利44%，10年国债30%，黄金0%，人民币货币ETF26%。当前滞后的美股状态为**熊市趋势**；国内策略本身已不要求买创业板，所以当周没有额外减仓。
- 美股策略子账户：若战略纳指核心设30%，QQQ 30%，BIL 70%；若采用纯战术，则QQQ 0%，BIL 100%。均以当前纳指跌破30周线为前提。

不是对用户所有持仓的即时清仓/买卖建议：税务、已持仓成本、账户币种、长期核心风险预算应单独决定。

## 6. 运行与验证

Windows：`run_windows.bat`；WSL/Unix：建立虚拟环境后 `pip install -r requirements.txt`，运行 `python -m streamlit run app.py`，在侧边栏选择“V15中美双策略与美股联动”。

命令行复现：`python scripts/reproduce_v15.py`。输出到 `research_outputs/V15_*`，包含两区策略信号、交易日志、对照CSV、最新风险状态。回归：`python -m pytest -q tests`。建议未来替换本地静态快照为每周自动拉取，并保留新旧数据文件哈希与交易日历校验。

## 7. 工程与研究局限

- 2026年回测对规则形成有影响，不是独立的样本外检验；没有置信度或保证收益。
- 美国ETF成交额和RSP/SPY强弱仅是代理信号，不等价于个股前5%成交集中度，更不等价于真实市场广度。
- V14原始研究数据有历史已知行情调参问题，跨市场联动不能修复它。
- 中国风险闸门**只控制新增加仓**，不替代日度隔夜恐慌退出；要验证真正的周一及时退出须构建双市日频引擎。
- 目前美元基金和人民币基金不跨账户交易，不涉及杠杆、期货或自动下单。完整资产组合需要汇率与交易费用核算。
